
# 🌐 Computer Networking Fundamentals

This repository offers a comprehensive, beginner-friendly guide to computer networking fundamentals—complete with structured notes, visual hierarchies, protocol deep-dives, and hands-on commands—crafted for aspiring network engineers, cloud architects, and DevOps practitioners. 🚀 Whether you’re starting from zero or leveling up your infrastructure skills, you’ll gain a clear, practical understanding of how data moves across the internet, backed by real-world examples and CLI exercises you can run today. 

---

## 🗺️ What’s Inside?

The repository is organized into logical modules, tracking everything from raw physical signals to modern cloud networking:

### 📑 1. Core Architecture & Models
* **OSI Model vs. TCP/IP Stack:** In-depth breakdowns of all 7 (and 4) layers.
* **Network Topologies:** Star, Mesh, Hybrid, and Ring structures.
* **Types of Networks:** PAN, LAN, MAN, WAN, and WLAN concepts.

### 🔢 2. Addressing & Routing
* **IP Addressing:** IPv4 vs. IPv6 structures and CIDR notation.
* **Subnetting & VLSM:** Step-by-step guides to breaking down network segments.
* **Routing Protocols:** Static routing, RIP, OSPF, and BGP mechanics.
* **MAC & ARP:** How hardware addresses map to IP addresses.

### ⚙️ 3. Protocols & Data Transfer
* **Transport Layer:** Deep dive into TCP (handshakes, flow control) vs. UDP.
* **Application Services:** DNS, DHCP, HTTP/HTTPS, FTP, and SMTP.
* **Traffic Control:** NAT/PAT (Network Address Translation) and Load Balancing.

### 🛡️ 4. Network Infrastructure & Security
* **Hardware Devices:** Operation of Hubs, Switches, Routers, Firewalls, and Access Points.
* **Security Essentials:** Access Control Lists (ACLs), VPNs, IDS/IPS, and Wireless Security.
* **DevOps Utilities:** Troubleshooting with `ping`, `traceroute`, `netstat`, `dig`, and `curl`.

## 🛠️ Getting Started & Resources

Choose your learning path depending on how you prefer to digest the material:

* **📁 `/Notes`:** Markdown summaries and cheat sheets for quick reference.
